Videos
======

NosTale stores some MPEG videos with custom extensions under `wave`.

| Extension | Contents                                                    |
| --------- | ----------------------------------------------------------- |
| `.ntm`    | Intro movies, such as `intromv001.ntm`.                     |
| `.nam`    | Act scene and eyecatch movies, often localized by filename. |

The files are ordinary MPEG Program Stream videos with NosTale-specific file
extensions.
